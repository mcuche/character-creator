# Session Summary — 2026-04-17

## What was done

App was ~95% implemented on arrival. Audited the full codebase, then filled gaps from DESIGN.md:

### New features
1. **Wizard guard** — Angular route guard preventing navigation to future steps before completing earlier ones. Redirects to first unlocked step.
2. **Cascade reset warnings** — Confirmation modals on Profession, Age, and Attributes steps when changing a value that wipes downstream data (skills, attributes, derived stats respectively).
3. **Gold/Silver/Copper tracker** — Added currency fields to `Character` model and `CharacterDraft`. UI added to character sheet Gear tab with +/− buttons per denomination.
4. **Pointer cursor** — Global CSS `cursor: pointer` for all enabled buttons and links.

### Bug fixes
- Currency spread order wrong: `{ gold: 0, ...char }` → `{ ...char, gold: char.gold ?? 0 }`
- Template `$any()` indexing (TS7053) on currency rows → replaced with explicit typed rows per coin type
- `tsconfig.app.json` missing `rootDir` causing TS error → added `"rootDir": "./src"`
